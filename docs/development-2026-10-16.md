# 2026-10-16 开发与验证记录

本记录整理本轮功能、适用范围和验证结果，不包含个人存档、机器路径或原始诊断日志。

## 完成的功能

- 存档按实际档案目录和本地 / 云存档分组；同名档案分别展示，切换时清除旧存档相关状态。
- 更换当前挂车和替换自有车辆配件，自动解密并读取支持的存档格式，另存命名副本。
- 可选的斯堪尼亚三屏电视预设：验证 DLC、挂点及资源哈希，资源缺失或冲突时拒绝覆盖。
- 车队经济管理：招聘司机、复制模板车辆或使用闲置卡车、分配多个车库、修复可核实的司机车辆参数，展示历史净收益。
- 未购车库可直接设为 3 / 5 车位，已有车库可扩容；支持筛选和批量规划，不移动现有车辆及司机，不直接增加现金。
- 单辆车永久容量扩展：柴油按升，斯堪尼亚 S 2024 电动 4×2 按 kWh；默认 5000，独立底盘 Mod 配合新存档，原档保留。
- 自动无限油量 / 电量共用一个写入线程且互斥；TruckersMP 专用例外仅限这两项，Unknown 和其他写入继续保留各自拦截。
- ETS2 1.61.1.9 定位支持：新增独立指纹和燃油计算指令校验，燃油校正偏移从旧版的 `+0x1158` 分离为 `+0x1180`。

只提交源码、构建 / 开发脚本、合成测试及文档。原厂底盘全文改为本地生成，生成文件及提取目录不提交。
