# 双游戏切换、恢复与验证

## 游戏隔离

- 目标进程由明确选择决定：欧卡 `eurotrucks2.exe`，美卡 `amtrucks.exe`。
- 存档、配置、相机按键、导出和联机日志按所选游戏的 Windows 文档目录定位。
- 两种导出在后台执行，结果由界面线程接收；「解密导出选中」保留解密后的格式，「导出可读 SII」把 BSII v3 转为 `SiiNunit` 文本，已有文本原样保留。
- 可读文本最多 128 MiB，未知版本、损坏内容和 3nK 可读转换均拒绝。临时文件与目标同目录，发布时不覆盖；取消和失败清理本次临时文件，源存档保持不变。
- Steam 云存档分别使用 `227300` / `270880`，备份目录及游戏标签防止跨游戏还原。
- 恢复来源使用规范化的绝对路径比较，检查目录边界，并支持当前游戏的云存档根目录。
- 遥测共享内存必须与当前选择的游戏 ID 匹配；欧卡为 1，美卡为 2。

## 切换生命周期

先取消并等待扫描线程，再停止车辆锁定和冻结器、尝试恢复发动机，最后关闭旧进程句柄。
旧扫描地址、存档选择、缓存数值、相机和飞行配置、联运显示、待确认对话框及传送输入被清空。
各游戏传送收藏分别保留。发动机恢复凭据按游戏分别保存在 `engine_state` 与 `engine_state_ats`，只导入当前游戏。
尚未确认恢复的发动机记录会阻止切换，避免遗失原厂值。

## 保留的内存保护

- 结构化金钱/经验定位遇到同分歧义、候选截断或对象关系不符时拒绝自动写入。
- 车辆固定指针只用于已匹配当前游戏进程与版本指纹的布局；油量及损伤需要范围和遥测交叉校验。
- 车辆事务先读取所有待写字段；写入失败或命令过期时尝试精确回滚。
- 回滚不覆盖外部已改变的字段；无法确认回滚时停止锁定并报告失败，不虚报自动恢复成功。
- 所有写入继续经过联机守卫。发动机原值、部分事务凭据和持久化恢复逻辑保留。

美卡 1.61.3.1 使用独立入口与运行时布局，支持银行类型自动定位金额、无限油量、无损和动力。
银行类型、经济类型、六项技能和银行引用必须匹配；汽车 DLC 高转速发动机仍须唯一类型匹配。
通用扫描器、存档、配置及控制台工具仍可使用。防侧翻实现和相关测试已删除。

## 验证边界

`--gametest` 使用真实合成遥测缓冲区、当前进程内存、独立设置与合成存档，覆盖跨游戏拒绝、
切换缓存清理、收藏及恢复凭据隔离、事务写入/回滚和原有发动机、经济定位回归。
`--crosstest` 仅对自行启动的专用靶子进程读写；界面冒烟运行两种游戏选择。
报告保存在 `cpp/build`。离线通过不代表真实游戏对象偏移、车辆效果或长时间运行已经验证。
BSII 名称顺序核对与可读导出副本测试不等于游戏载入验收；存档复制、卡车导入、档案拆分及转换文本仍须在游戏中单独确认。
已对真实美卡执行只读对象核对，尚未执行真实写入验收；个人存档、插件与游戏安装文件未被修改。

## 运行诊断完善

实时日志使用独立会话文件、互斥串行写入并逐行刷新；并发写入、运行期间读取、清空界面保留
磁盘证据和拒绝覆盖既有会话均有离线回归。日志写入失败会在界面显示具体路径和错误。

只读进程接口不申请 VM_WRITE/VM_OPERATION，并在 API 层拒绝写入。真实只读诊断先检查遥测，
独立报告进程权限错误；未通过时返回失败状态。美卡按自己的版本指纹检查车辆、发动机和经济对象。
取得主映像可以使用只读 PEB 查询；该查询不会绕过模块枚举失败时的联机写入拦截。
美卡直接改钱不要求当前余额；版本不匹配时在扫描前拒绝。切换游戏后必须重新附加。
